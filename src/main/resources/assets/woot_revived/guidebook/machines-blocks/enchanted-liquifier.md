# Enchanted Liquifier

<BlockImage id="enchanted_liquifier" scale="5"/>

The <ItemImage id="enchanted_liquifier" scale="0.5"/> Enchanted Liquifier produces <ItemImage id="enchanted_fluid_bucket" scale="0.5"/> Enchanted Fluid by liquifying enchanted books.

Each <ItemImage id="minecraft:enchanted_book" scale="0.5"/> enchanted book level will produce a bucket of <ItemImage id="enchanted_fluid_bucket" scale="0.5"/> Enchanted Fluid. To a limit of 10 levels.

That means if the book have an enchantment with a level higher than X it will count as an X enchantment.
